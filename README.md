# Бот анонимных вопросов

Telegram-бот на Python, aiogram 3 и SQLite. Пользователь получает личную ссылку,
по ней ему можно отправить вопрос. Кнопка «Ответить» доступна только получателю
вопроса. Бот работает в личных чатах.

Поддерживаются текст, фото, видео, GIF, документы, голосовые сообщения, аудио,
кружочки и стикеры. Альбом обрабатывается как отдельные сообщения; общий лимит
вопросов применяется к каждому из них.

## Настройка и запуск

Нужен Python 3.10 или новее и доступ к Telegram Bot API. Проверено на Python 3.14.
Запускайте один процесс бота с одним токеном.

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте `.env.example` в `.env` рядом с `bot.py`.
3. Задайте `BOT_TOKEN` и `ADMIN_ID`. ID администратора — положительный числовой
   Telegram ID вашего аккаунта, не `@username` и не ID бота. Узнать свой ID можно,
   например, через [@userinfobot](https://t.me/userinfobot).
4. Установите зависимости и запустите бот из папки проекта.

Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (!(Test-Path .env)) { Copy-Item .env.example .env }
.\.venv\Scripts\python.exe bot.py
```

Linux / macOS:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
cp -n .env.example .env
.venv/bin/python bot.py
```

| Переменная | Значение |
| --- | --- |
| `BOT_TOKEN` | Обязательный токен из @BotFather |
| `ADMIN_ID` | Обязательный положительный числовой ID администратора |
| `QUESTION_COOLDOWN_SECONDS` | Минимальный интервал между вопросами одного отправителя; по умолчанию `30`, целое число больше нуля |

`.env` всегда читается из папки проекта. Переменные окружения имеют приоритет.
При неверных настройках запуск завершается с названием проблемной переменной,
без вывода её значения. Файл `.env` исключён из Git.

После запуска откройте бота и отправьте `/start`. Получатель должен сначала
сам запустить бота, чтобы получить ссылку и принимать вопросы. Остановка —
`Ctrl+C`. Используется long polling, публичный HTTP-сервер не нужен.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Регистрация и личная ссылка; переход по чужой ссылке открывает ввод вопроса |
| `/mylink` | Повторно показать свою ссылку |
| `/help` | Список команд |
| `/cancel` | Отмена ввода вопроса, ответа или рассылки |
| `/stats` | Только администратор: число пользователей и сохранённых попыток отправки вопросов |
| `/broadcast` | Только администратор: следующее сообщение рассылается пользователям; до отправки можно отменить через `/cancel` |
| `/debug` | Только администратор: сообщает, что debug-пересылка удалена; включить её нельзя |

Чтобы ответить, нажмите «Ответить» под полученным вопросом и отправьте сообщение.
Право на ответ проверяется и при нажатии, и перед отправкой. Автор для доставки
ответа берётся из базы, а не из данных сессии. Чужие, некорректные и недоступные
кнопки показывают пояснение. Кнопка удалённого из базы вопроса считается
устаревшей. Срока давности и ограничения на число ответов у существующего вопроса нет.
